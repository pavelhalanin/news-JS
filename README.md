# news-JS

## How to run

1. Install [Git](https://git-scm.com/)
1. Install [NodeJS](https://nodejs.org/en)
1. Clone repo
    ```
    git clone https://github.com/pavelhalanin/news-JS.git news-JS_pavelhalanin
    ```
1. Open folder
    ```
    cd news-JS_pavelhalanin
    ```
1. Install node modules
    ```
    npm i
    ```
1. Copy `.env.example` to `.env` and set variables with your data
1. Start
    ```
    npm run start
    ```
1. Enjoy and coffee

## How to start format with Prettier
